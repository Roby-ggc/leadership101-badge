# LEADERSHIP 101 — Générateur de badges

## Démarrage
Ouvrir `index.html` dans un navigateur.

## Ajouter le flyer officiel
Copier le flyer dans le dossier `images` et le nommer :
- `flyer.jpg`, ou
- `flyer.png`

Le site essaie automatiquement ces deux noms.

## Personnalisation
Le participant importe sa photo, saisit son nom et télécharge son badge en PNG.

Aucune base de données ou connexion n'est nécessaire.
